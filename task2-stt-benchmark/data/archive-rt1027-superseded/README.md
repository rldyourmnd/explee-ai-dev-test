# Superseded: the Радио-Т corpus (`rt1027`)

Everything in this directory describes a corpus we **no longer use** and results
that are **not** the benchmark's findings. It is kept because the reasoning is
part of the record, and deleted files cannot be audited.

`rt1027` was a four-host podcast: right acoustics, right code-switching, no
independent transcript. Without one, the only available reference would have
been derived from the engines under test, which measures agreement rather than
accuracy. It was replaced by a conference talk that ships with a human
transcript published by the source (`hlk8s`).

**Do not read these numbers as current.** The live results are
`data/results-hlk8s.json` and the published report.
